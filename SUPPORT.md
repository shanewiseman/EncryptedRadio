# Support

EncryptedRadio is at the repository-initialization stage. There are no supported releases, end-user installation instructions, or service commitments yet.

For project questions, defects, or proposals, search existing GitHub issues first and then open an issue if needed. Include the objective, relevant revision, expected and actual behavior, and reproduction steps where applicable. Use the [task template](docs/TASK_TEMPLATE.md) for implementation requests. Remove secrets and personal information from logs and examples before sharing them.

Report vulnerabilities through the private process in [SECURITY.md](SECURITY.md). Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) in all project interactions.

Development starts with [README.md](README.md), [AGENTS.md](AGENTS.md), and [CONTRIBUTING.md](CONTRIBUTING.md). Product requirements and unresolved decisions are tracked in [docs/PROJECT.md](docs/PROJECT.md).
